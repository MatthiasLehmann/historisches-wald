# Local fonts

These variable fonts are served from this site's own `/fonts/` directory.
Keep the accompanying SIL Open Font License files with the fonts.

Downloaded on 2026-10-06 from the official Google Fonts repository:

- `inter-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
- `playfair-display-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/playfairdisplay/PlayfairDisplay%5Bwght%5D.ttf
- `playfair-display-italic-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/playfairdisplay/PlayfairDisplay-Italic%5Bwght%5D.ttf

The build requires no external font service. The font names, normal weights,
and Playfair Display italic style are declared in `src/index.css`.
